# True-Doctor user manual

This manual explains how to use True-Doctor, the hospital and clinic management system, from the first sign-in to the end of the financial year. It is written for everyone who works in it: owners and administrators, doctors and nurses, receptionists and cashiers, pharmacists, lab and radiology staff, and records officers. Each chapter covers one part of the work. You only see the menus your role allows, so some chapters may describe pages you do not have. Start with chapter 1, then go to the chapters for your own work.
